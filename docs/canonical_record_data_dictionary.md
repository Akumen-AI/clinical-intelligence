# Canonical Patient Record — Data Dictionary

> **Scope**: This dictionary covers the canonical patient record schema added in Epic 8.
> It does **not** cover the extraction pipeline tables (`documents`, `extracted_fields`,
> `pending_review`, `correction_logs`), which are documented separately.
>
> **Source annotation key**:
> - **Manual entry** — populated by a human operator via the CRUD API (`POST /api/v1/patients/…`)
> - **Extraction pipeline** — populated when the extraction pipeline writes into these tables
>   (Epic 9 follow-up; not yet implemented).  The `source_document_id` FK links back to the
>   originating document.
> - **System** — set automatically by the application (UUID generation, timestamps).

---

## Table: `patients`

Primary canonical identity record for a patient.

| Column | Type | Nullable | Description |
|---|---|---|---|
| `id` | `VARCHAR(36)` | NOT NULL | Primary key — UUID string generated by the application (`str(uuid.uuid4())`). Matches the format of `documents.patient_id`, enabling the FK join. **Source: System** |
| `name` | `VARCHAR(255)` | NOT NULL | Full patient name. **Source: Manual entry** |
| `dob` | `DATE` | NULL | Date of birth in `YYYY-MM-DD` format. **Source: Manual entry** |
| `gender` | `VARCHAR(50)` | NULL | Patient gender (e.g. `male`, `female`, `other`, `unknown`). **Source: Manual entry** |
| `mrn` | `VARCHAR(50)` | NULL | Medical Record Number. Not enforced as unique at DB level yet; a UNIQUE constraint can be added via migration once data hygiene guarantees it. **Source: Manual entry** |
| `created_at` | `DATETIME(tz)` | NOT NULL | UTC timestamp of record creation. **Source: System** |
| `updated_at` | `DATETIME(tz)` | NOT NULL | UTC timestamp of last update; refreshed on every `PUT /api/v1/patients/{id}` call. **Source: System** |

**Indexes**: `ix_patients_id` (PK), `ix_patients_mrn`

**Constraints / FKs coming from other tables**:
- `documents.patient_id` → `patients.id` (FK `fk_documents_patient_id`, `ON DELETE SET NULL`; added in migration 005)

---

## Table: `visits`

One clinical encounter / visit for a patient.

| Column | Type | Nullable | Description |
|---|---|---|---|
| `id` | `VARCHAR(36)` | NOT NULL | Primary key — UUID string. **Source: System** |
| `patient_id` | `VARCHAR(36)` | NOT NULL | FK → `patients.id` (`ON DELETE CASCADE`). **Source: System (set from URL path param)** |
| `visit_date` | `DATE` | NULL | Calendar date of the visit (`YYYY-MM-DD`). **Source: Manual entry** |
| `visit_type` | `VARCHAR(100)` | NULL | Encounter type (e.g. `outpatient`, `inpatient`, `ER`, `telehealth`). **Source: Manual entry** |
| `notes` | `TEXT` | NULL | Free-text clinical notes for the visit. **Source: Manual entry** |
| `created_at` | `DATETIME(tz)` | NOT NULL | UTC timestamp of record creation. **Source: System** |

**Indexes**: `ix_visits_id` (PK), `ix_visits_patient_id`

---

## Table: `medications`

Medication prescribed or administered, optionally associated with a visit.

| Column | Type | Nullable | Description |
|---|---|---|---|
| `id` | `VARCHAR(36)` | NOT NULL | Primary key — UUID string. **Source: System** |
| `patient_id` | `VARCHAR(36)` | NOT NULL | FK → `patients.id` (`ON DELETE CASCADE`). **Source: System** |
| `visit_id` | `VARCHAR(36)` | NULL | FK → `visits.id` (`ON DELETE SET NULL`). Null if medication is not tied to a specific visit. **Source: Manual entry / Extraction pipeline** |
| `name` | `VARCHAR(255)` | NOT NULL | Medication name (brand or generic). **Source: Manual entry / Extraction pipeline** |
| `dosage` | `VARCHAR(100)` | NULL | Dose amount and form (e.g. `500mg`, `10mg/5ml`). **Source: Manual entry / Extraction pipeline** |
| `frequency` | `VARCHAR(100)` | NULL | Dosing frequency (e.g. `twice daily`, `every 8 hours`). **Source: Manual entry / Extraction pipeline** |
| `start_date` | `DATE` | NULL | Date medication was started. **Source: Manual entry / Extraction pipeline** |
| `end_date` | `DATE` | NULL | Date medication was stopped or is scheduled to stop. **Source: Manual entry / Extraction pipeline** |
| `status` | `VARCHAR(50)` | NULL | Medication status (e.g. `active`, `discontinued`, `on-hold`). **Source: Manual entry** |
| `source_document_id` | `VARCHAR(36)` | NULL | FK → `documents.document_id` (`ON DELETE SET NULL`). Set when this record was extracted from a document via the extraction pipeline. Null for manually-entered records. **Source: Extraction pipeline** |
| `created_at` | `DATETIME(tz)` | NOT NULL | UTC timestamp of record creation. **Source: System** |

**Indexes**: `ix_medications_id` (PK), `ix_medications_patient_id`, `ix_medications_visit_id`, `ix_medications_source_document_id`

---

## Table: `diagnoses`

Clinical diagnosis attached to a patient, optionally to a visit.

| Column | Type | Nullable | Description |
|---|---|---|---|
| `id` | `VARCHAR(36)` | NOT NULL | Primary key — UUID string. **Source: System** |
| `patient_id` | `VARCHAR(36)` | NOT NULL | FK → `patients.id` (`ON DELETE CASCADE`). **Source: System** |
| `visit_id` | `VARCHAR(36)` | NULL | FK → `visits.id` (`ON DELETE SET NULL`). Null if diagnosis is not tied to a specific visit. **Source: Manual entry / Extraction pipeline** |
| `description` | `TEXT` | NOT NULL | Human-readable diagnosis description or ICD-10 code + label (e.g. `E11.9 — Type 2 diabetes mellitus without complications`). **Source: Manual entry / Extraction pipeline** |
| `diagnosis_date` | `DATE` | NULL | Date the diagnosis was made or recorded. **Source: Manual entry / Extraction pipeline** |
| `source_document_id` | `VARCHAR(36)` | NULL | FK → `documents.document_id` (`ON DELETE SET NULL`). Populated when extracted from a document. **Source: Extraction pipeline** |
| `created_at` | `DATETIME(tz)` | NOT NULL | UTC timestamp of record creation. **Source: System** |

**Indexes**: `ix_diagnoses_id` (PK), `ix_diagnoses_patient_id`, `ix_diagnoses_visit_id`, `ix_diagnoses_source_document_id`

## Table: `vitals`

Single vital-sign measurement for a patient.

| Column | Type | Nullable | Description |
|---|---|---|---|
| `id` | `VARCHAR(36)` | NOT NULL | Primary key — UUID string. **Source: System** |
| `patient_id` | `VARCHAR(36)` | NOT NULL | FK → `patients.id` (`ON DELETE CASCADE`). **Source: System** |
| `visit_id` | `VARCHAR(36)` | NULL | FK → `visits.id` (`ON DELETE SET NULL`). **Source: Manual entry / Extraction pipeline** |
| `vital_type` | `VARCHAR(100)` | NOT NULL | Type of measurement (e.g. `blood_pressure`, `heart_rate`, `temperature`, `spo2`, `weight`, `height`, `bmi`, `respiratory_rate`). **Source: Manual entry / Extraction pipeline** |
| `value` | `VARCHAR(100)` | NOT NULL | Measured value as a string to accommodate ranges (e.g. `120/80`, `36.6`, `98.4`). **Source: Manual entry / Extraction pipeline** |
| `unit` | `VARCHAR(50)` | NULL | Measurement unit (e.g. `mmHg`, `bpm`, `°C`, `°F`, `kg`, `%`). **Source: Manual entry / Extraction pipeline** |
| `recorded_at` | `DATETIME(tz)` | NULL | UTC timestamp when the vital was recorded. Distinct from `created_at` which is when the row was inserted. **Source: Manual entry / Extraction pipeline** |
| `source_document_id` | `VARCHAR(36)` | NULL | FK → `documents.document_id` (`ON DELETE SET NULL`). Populated when extracted from a document. **Source: Extraction pipeline** |
| `created_at` | `DATETIME(tz)` | NOT NULL | UTC timestamp of record creation. **Source: System** |

**Indexes**: `ix_vitals_id` (PK), `ix_vitals_patient_id`, `ix_vitals_visit_id`, `ix_vitals_source_document_id`

---

## Table: `labs`

Laboratory test result for a patient.

| Column | Type | Nullable | Description |
|---|---|---|---|
| `id` | `VARCHAR(36)` | NOT NULL | Primary key — UUID string. **Source: System** |
| `patient_id` | `VARCHAR(36)` | NOT NULL | FK → `patients.id` (`ON DELETE CASCADE`). **Source: System** |
| `visit_id` | `VARCHAR(36)` | NULL | FK → `visits.id` (`ON DELETE SET NULL`). **Source: Manual entry / Extraction pipeline** |
| `test_name` | `VARCHAR(255)` | NOT NULL | Name of the lab test (e.g. `HbA1c`, `Complete Blood Count`, `Creatinine`). **Source: Manual entry / Extraction pipeline** |
| `result_value` | `VARCHAR(100)` | NULL | Numeric or text result (e.g. `6.2`, `Positive`, `<0.1`). Stored as string to handle text and bound results. **Source: Manual entry / Extraction pipeline** |
| `unit` | `VARCHAR(50)` | NULL | Result unit (e.g. `%`, `mg/dL`, `mmol/L`). **Source: Manual entry / Extraction pipeline** |
| `reference_range` | `VARCHAR(100)` | NULL | Normal reference range for the test (e.g. `4.0–5.6`, `<200`). **Source: Manual entry / Extraction pipeline** |
| `test_date` | `DATE` | NULL | Date the sample was collected or the test was performed. **Source: Manual entry / Extraction pipeline** |
| `source_document_id` | `VARCHAR(36)` | NULL | FK → `documents.document_id` (`ON DELETE SET NULL`). Populated when extracted from a document. **Source: Extraction pipeline** |
| `created_at` | `DATETIME(tz)` | NOT NULL | UTC timestamp of record creation. **Source: System** |

**Indexes**: `ix_labs_id` (PK), `ix_labs_patient_id`, `ix_labs_visit_id`, `ix_labs_source_document_id`

| `created_at` | `DATETIME(tz)` | NOT NULL | UTC timestamp of record creation. **Source: System** |

**Indexes**: `ix_procedures_id` (PK), `ix_procedures_patient_id`, `ix_procedures_visit_id`, `ix_procedures_source_document_id`

                        visits.patient_id          (child tables all reference)

                    ┌──────┴──────┐                     │
                    │             │                     │
           medications.visit_id   │              medications.patient_id
           diagnoses.visit_id     │              diagnoses.patient_id

## API Endpoints Summary

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/v1/patients` | Create patient |
| `GET` | `/api/v1/patients/{patient_id}` | Full canonical record |
| `PUT` | `/api/v1/patients/{patient_id}` | Update demographics |
| `POST` | `/api/v1/patients/{patient_id}/visits` | Add visit |
| `PUT` | `/api/v1/patients/{patient_id}/visits/{visit_id}` | Update visit |
| `POST` | `/api/v1/patients/{patient_id}/medications` | Add medication |
| `PUT` | `/api/v1/patients/{patient_id}/medications/{medication_id}` | Update medication |
| `POST` | `/api/v1/patients/{patient_id}/diagnoses` | Add diagnosis |
| `PUT` | `/api/v1/patients/{patient_id}/diagnoses/{diagnosis_id}` | Update diagnosis |
| `POST` | `/api/v1/patients/{patient_id}/vitals` | Add vital sign |
| `PUT` | `/api/v1/patients/{patient_id}/vitals/{vital_id}` | Update vital |
| `POST` | `/api/v1/patients/{patient_id}/labs` | Add lab result |
| `PUT` | `/api/v1/patients/{patient_id}/labs/{lab_id}` | Update lab |
| `POST` | `/api/v1/patients/{patient_id}/procedures` | Add procedure |
| `PUT` | `/api/v1/patients/{patient_id}/procedures/{procedure_id}` | Update procedure |

> **Auth**: No authentication is applied to these routes, consistent with all existing routes
> in this project. Retrofitting RBAC is tracked in **Epic 9**.
